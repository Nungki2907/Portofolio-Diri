The Journey of Creating a "Personal Portfolio" Website🌸

✦ Recount Text ✦

Orientation

In the second semester of the 2025/2026 academic year, the 10th grade students of the Software and Game Development major (PPLG) were assigned to create a website about their personal portfolio. Besides personal biodata, the website also contains personal skills in programming, such as HTML, CSS, and JavaScript. This website also includes six website projects that had previously been created, such as the collaborative website project from semester 1, a school website, a nature-themed website, a free-themed website, and a Furniture and Home Decor website (for attendance tasks 21–25). In this text, I will share my challenging experience of creating a website for the cross-subject collaboration assignment.

Event

The steps for creating the website this semester felt fewer compared to last semester. However, the application used to design the website interface this time was more complicated than before because we used Figma, an application I had never used before. Last semester, I used Canva.

Although it felt difficult at first, over time it gradually became easier. Whenever there was something I wanted to design but did not know how to make, I searched for tutorials using AI, Google, and other sources. That was one of the things that slowly helped me learn how to use Figma. In the design stage, I needed about one week to finish it. It actually took quite a long time, but one of the reasons was the large number of assignments I had to complete. Therefore, I had to manage my time between working on the collaboration project and other school assignments.

Even though using Figma was more complicated than Canva, I still managed to complete the design, and I was very satisfied with the result. However, I still had to ask for approval from the Basic Software Development teacher. At first, I had to revise several parts of the design. Eventually, my website design was approved and had to be printed as one of the assignment submission requirements.

After the design process was finished, I decided to take a short rest because I had stayed up late working on it.

After that, I continued to the next stage, which was implementing the code to create a website appearance similar to the design. During this process, I was also helped by AI, especially because I needed JavaScript for this website.

The coding process is still ongoing. It is one of the longest stages because if there is even a small mistake in writing HTML or CSS tags, the website display can become broken or experience errors.

Since my website design is quite complicated and contains many decorative elements, it requires many CSS tags and a lot of lines of code. I placed the HTML, CSS, and JavaScript files separately to keep everything neat and organized. Connecting them was not too difficult because it could be done using links. The coding would also be connected with Bootstrap.

When the website is finally completed, the next thing I need to do is testing the website to make sure everything works properly. If there are any problems, I will check what caused them and try to fix them. Once there are no more issues, the final step will be publishing the website, for example on GitHub.

Reorientation

Creating a website is not an easy task. Stress and headaches often happen, for example when I am designing but have no inspiration. However, once the website is completed, it gives me a great sense of satisfaction and happiness. Especially for someone like me who truly started learning coding from zero, feelings of pride and joy always appear whenever I successfully finish my own website.
